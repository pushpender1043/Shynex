## 🚀 About The Project

**Shynex** is not just an e-commerce store; it's an experience. Built with the **MERN Stack**, it combines a "Luxury" aesthetic with robust backend engineering. The goal was to create a shopping platform that feels fluid, responsive, and secure.

From a **customized cursor** to **fluid animations** and a powerful **Admin Dashboard**, Shynex demonstrates the power of modern web development.

---

## 🔥 Key Features

### 🎨 Immersive UI/UX
* **Custom Cursor & Animations:** A unique, interactive browsing experience.
* **Fully Responsive:** Flawless layout on Mobile, Tablet, and Desktop.
* **Modern Design:** Minimalist, premium aesthetic suited for high-end fashion.

### 🔐 Advanced Security
* **Dual Authentication:**
    * **Google OAuth (Firebase):** One-click "Continue with Google".
    * **JWT (JSON Web Tokens):** Secure, stateless session management for API protection.

### 🛒 E-Commerce Functionality
* **Razorpay Integration:** Full payment gateway integration for real-time transactions.
* **Cart & Wishlist:** Seamless state management for user shopping bags.

### 👨‍💻 Admin Superpowers
* **Admin Dashboard:** Complete CMS to manage Products, Orders, and Users.
* **CRUD Operations:** Add, Edit, or Delete products dynamically.
* **Order Tracking:** Monitor order status in real-time.

## ⚙️ Installation & Setup

Want to run this locally? Follow these steps:

1.  **Clone the Repo**
    ```bash
    git clone [https://github.com/pushpender1043/Shynex.git](https://github.com/pushpender1043/Shynex.git)
    cd Shynex
    ```

2.  **Install Dependencies**
    ```bash
    # Install server dependencies
    cd backend
    npm install

    # Install client dependencies
    cd ../frontend
    npm install
    ```

3.  **Environment Variables**
    Create a `.env` file in the backend folder and add:
    ```env
    PORT=4000
    MONGO_URI=your_mongodb_uri
    JWT_SECRET=your_jwt_secret
    RAZORPAY_API_KEY=your_key
    RAZORPAY_API_SECRET=your_secret
    FIREBASE_API_KEY=your_firebase_key
    ```

4.  **Run the App**
    ```bash
    # Run Backend
    cd backend
    npm start

    # Run Frontend
    cd frontend
    npm start
    ```
